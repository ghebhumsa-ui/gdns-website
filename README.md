# GDNS website

English website for Gorkha Dukha Niwarak Sammelan, Darjeeling, established in 1932.

## Hosting

GitHub Pages serves the repository root from the `main` branch. `.nojekyll` preserves the static assets. No build or package installation is needed.

## Editing

- `index.html`: navigation, footer and global contact details.
- `app.js`: page templates, routing, programme search and enquiry forms.
- `styles.css`: responsive design.
- `content/en.js`: programme, history, objective and project content.
- `content/members.en.js`: executive committee names, roles and portrait framing.
- `assets/`: supplied logo, brochure pages and executive committee list.

Contact email: sammelangdns@gmail.com.

Member names were transcribed from the supplied Nepali committee list. English transliterations should be reviewed by GDNS. No term dates were supplied.

Membership and suggestion forms open email drafts; they do not send or store submissions. Donations are handled through enquiries, not online payments. This version has no CMS or member accounts. Other language editions remain future work.
